# Architecture decision records

An architecture decision record (ADR) explains a selected design, the alternatives considered and the consequences. An accepted decision describes a chosen design; it does not by itself mean the design is implemented or tested.

| Record | Subject |
| --- | --- |
| [ADR-0002](0002-hosted-hybrid.md) | Hosted hybrid deployment and free stack |
| [ADR-0003](0003-state-ownership.md) | State and data ownership, recipient exclusivity and manual changes |
| [ADR-0004](0004-send-reconciliation.md) | Execution lease and uncertain-send reconciliation |
| [ADR-0005](0005-free-pilot-operations.md) | Free-pilot quality targets, retention and recovery constraints |

These records reflect the architecture approved on 30 September 2026. Read the [architecture index](../architecture/README.md) for design detail. When a decision changes, add a new record that supersedes the old one instead of rewriting it.
